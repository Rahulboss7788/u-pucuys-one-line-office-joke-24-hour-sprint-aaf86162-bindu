# One-Line Office Joke: 24-Hour Sprint

A single-line joke about office life — the reply-all / inbox disaster angle: an out-of-office auto-reply loops with another one, and two robots end up holding a meeting without you. Written for the make.fun competition "One-Line Office Joke: 24-Hour Sprint".

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` and verifies it is a single line of 1–200 characters.
